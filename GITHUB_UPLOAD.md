# Upload the Python demo to GitHub

1. Create a private repository and copy the contents of this folder into it.
2. Check that backend/.env, user data, API keys, and private database exports are not included.
3. Commit and push the project. Keep database/groupmate_clean_setup.sql as the clean demo setup; do not replace it with a private live export.
4. Give teammates the repository and GROUPMATE_SETUP.md. Each person should use a local MySQL demo database and their own .env.

The demo is Python/FastAPI and does not require PHP or Apache to run. Keep database passwords and Groq keys in local .env files only.
